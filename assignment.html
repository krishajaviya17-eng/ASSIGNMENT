Interaction Design and Micro Interaction

Theory Assignments

1. Introduction to Interaction Design

Interaction design focuses on how users interact with websites and applications. Good interaction design makes products easy and enjoyable to use.

Example of good interaction: Buttons changing color when hovered by mouse.

Example of bad interaction: Confusing navigation and delayed response after clicking buttons.

2. Microinteractions

Microinteractions are small animations or responses that improve user experience.

Examples include: Like button animation, loading indicators, and notification sounds.

They make applications feel more interactive and engaging.

WCAG stands for Web Content Accessibility Guidelines. These guidelines help developers create websites that are accessible for all users, including people with disabilities. Inclusive design focuses on creating products usable by everyone. Accessibility improves user experience by making websites easier to use for visually impaired and disabled users. Inclusive design increases audience reach and improves customer satisfaction.

Introduction to CSS and Styling Basics

Theory Answers

1. Difference Between Inline, Internal, and External CSS

Inline CSS is written directly inside an HTML tag using the style attribute. Internal CSS is written inside the style tag in the head section. External CSS is written in a separate .css file and linked with HTML.

2. CSS Selectors

CSS selectors are used to select HTML elements for styling. Common selectors are:

  • Element Selector
  • Class Selector
  • ID Selector

3. CSS Box Model

The CSS box model contains content, padding, border, and margin. It controls spacing and layout of elements.
